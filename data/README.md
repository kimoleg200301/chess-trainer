# Учебная выборка Lichess

`puzzles.csv` содержит **2500 настоящих тактических задач** из [открытой базы Lichess](https://database.lichess.org/#puzzles). Это стартовая выборка, а не полная база сайта.

- Источник: <https://database.lichess.org/lichess_db_puzzle.csv.zst>.
- Дата получения: 31 октября 2026 года, UTC.
- Лицензия экспорта: [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). Исходный формат и ссылки на партии сохранены.
- Фактический диапазон рейтинга задач: **600–2391**. Это рейтинг задач Lichess, а не рейтинг игрока FIDE.
- Фильтры: рейтинг 600–2400, минимум 20 сыгранных попыток в исходной базе, популярность не ниже нуля, хотя бы одна из десяти выбранных тем.
- Порядок выборки: первые подходящие строки официального экспорта. Выборка не заявляется статистически репрезентативной.
- Все 2500 исходных позиций и полных последовательностей ходов прошли проверку легальности через `python-chess`.

## Семантика позиции и решения

**Поле FEN описывает позицию до последнего хода соперника.** Перед показом задачи нужно применить первый ход из поля `Moves`. Решение ученика начинается со второго элемента. Сторона ученика определяется по очереди хода после применения первого элемента. Не показывайте исходный FEN как готовое упражнение.

## Обновление выборки

Из корня проекта:

```bash
uv run scripts/import_lichess.py
```

Скрипт объявляет собственные зафиксированные зависимости в формате PEP 723; `uv` устанавливает их в отдельное кешируемое окружение. Установка библиотек в системный Python не нужна.

Пример других параметров:

```bash
uv run scripts/import_lichess.py --limit 5000 --min-rating 800 --max-rating 1800 --themes fork,pin,skewer --max-download-mb 16
```

Импорт потоковый: прекращается после достижения цели, 100000 просмотренных строк или лимита сжатых сетевых данных. По умолчанию лимит скачивания — 16 MiB. При создании текущей выборки просмотрено 4890 строк и прочитано **327680 байт** сжатых данных; полный архив не скачивался. Код завершения `2` означает, что сохранена неполная выборка из-за ограничения, `1` — ошибку; `0` — достижение цели. При отсутствии подходящих задач прежний файл остаётся нетронутым.

Файл `puzzles.metadata.json` содержит параметры, фактические счётчики, время получения, число скачанных байт и SHA-256 CSV. Обновление CSV меняет только источник импорта; загрузка новых строк в PostgreSQL выполняется командой подготовки базы из основного README проекта.
