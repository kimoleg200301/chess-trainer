# Проверка первой версии

Проверено в рабочей среде 31 октября 2026 года.

Тесты используют отдельную временную схему, проверяют авторизацию, владение попытками, Origin, скрытие решения, легальные ходы, альтернативный мат, повторения, статистику, экспорт и восстановление прогресса, границы статических/API-маршрутов.

- Экран 390 px: горизонтального переполнения нет. SVG фигур загружаются успешно; права файлов проверены внутри nginx-образа.

## Отдельный анализ партий и завершение личной коллекции

1 ноября 2026 года: добавлен независимый анализ всех ходов обеих сторон. Проверены собственная формула точности, оценки со стороны ходящего, мат и ничья, пороги категорий, исключение вынужденных ходов из среднего и отсутствие итогового процента при неполной проверке. Stockfish подтвердил корректные жертвы ферзя за белых и чёрных; регрессии защищают от ложной отметки обычного размена и неподтверждённой жертвы.

Результаты движка читаются из согласованных точных сообщений одной итерации поиска. Это устраняет ложный отказ из-за промежуточных bound-пометок, которые библиотека могла оставить при объединении сообщений. Проверены неполные итерации MultiPV, сохранение порога глубины, повторная проверка сомнительных результатов и тайм-аут зависшего потока. 33 теста расчёта прошли; три ранее пропущенных хода реальной партии получили оценку на глубине 15–16 за 1,6–3,2 секунды при 0,5 CPU / 512 МБ.

Интеграционные проверки PostgreSQL покрывают владение отчётами, сохранение каждого полухода, повторный запуск без дубликата, возобновление и пересчёт, конкуренцию запросов, неизменность задач и тренировочного прогресса, нестандартную начальную очередь хода и отбор 200 свежих партий до применения лимита. Миграция `0005_separate_game_analysis` применяется автоматически при запуске контейнера.

Личные задачи с завершённой попыткой или показанным ответом исключаются из обычной практики, включая смешанную базу и новую версию задачи из того же хода партии. Проверены возобновление активной попытки без дубликата, фильтры и владельцы, пропуск текущей позиции, отдельные ответы об окончании коллекции и явное повторение. На настоящем локальном API пройдена коллекция из трёх личных задач: последующие старты не добавили попыток, завершение сохранилось после повторного входа, явный запуск остался доступен.

Production-сборка и браузерные сценарии прошли: отдельный импорт без генерации задач, последовательные шаги анализа, паузы, продолжение после 503/409, запоздавшие ответы при переключении партии, предварительная и итоговая точность, категории, просмотр сыгранного хода и варианта, переворот доски. Экран завершения тренировки не содержит заголовков; частично решённая задача сохраняет позицию, таймер и правильное начало разбора. ## Воспроизводимый бенчмарк Stockfish

Полный набор backend-проверок: 163 теста прошли на PostgreSQL 17 с настоящим Stockfish. Проверены итоговый парсер bench, контрольное число узлов, NNUE/MultiPV 2, тайм-аут и аварийное завершение процесса, метаданные CPU/памяти, запуск CLI без настроек базы. API-тесты проверяют авторизацию, origin, владение результатом, запрет пользовательских аргументов, повторный запрос текущего задания, общий слот движка, ограничение частоты, истечение результата и освобождение ресурсов после ошибок. Диагностика не меняет партии, задачи и тренировочный прогресс.

Единый образ Render Free собран. В локальном контейнере с квотой 0,5 CPU и 512 МиБ выполнен настоящий HTTP-сценарий: вход, запуск задания, ожидание трёх измерений, получение JSON и выход. Все три запуска Stockfish 15.1 подтвердили профиль NNUE / MultiPV 2 и контрольное число 978533 узла. Эти измерения относятся только к локальному контейнеру; производительность опубликованного Render ими не подтверждается.

Клиент проверен на успешный ответ, сохранение результата, продолжение по ID без нового запуска, отказ занятого сервера, отсутствие endpoint, ошибку входа, частичный результат и истечение времени ожидания.
