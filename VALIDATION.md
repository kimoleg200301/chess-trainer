# Проверка первой версии

Проверено в рабочей среде 31 октября 2026 года.

- Backend: 11 интеграционных тестов успешно выполнены на PostgreSQL 17. Тесты используют отдельную временную схему, проверяют авторизацию, владение попытками, Origin, скрытие решения, легальные ходы, альтернативный мат, повторения и статистику.
- Frontend: строгая проверка TypeScript и production-сборка Vite успешны.
- Docker: оба production-образа собраны; nginx → FastAPI → PostgreSQL работает; Stockfish доступен.
- Chromium: проверены вход, фильтр мотивов/рейтинга, неверный ход, подсказка, полное решение с ответами соперника, Stockfish, показ и пошаговый просмотр решения, статистика, выход. Ошибок JavaScript нет.
- Экран 390 px: горизонтального переполнения нет. SVG фигур загружаются успешно; права файлов проверены внутри nginx-образа.
- Данные: все 2500 исходных линий проверены на допустимость ходов; начальная позиция учитывает первый ход соперника. Источник и контрольная сумма — `data/puzzles.metadata.json`.
- PostgreSQL: создана резервная копия в custom-формате, её каталог успешно прочитан через `pg_restore --list`.
- Compose: конфигурации разработки и VPS проходят проверку синтаксиса. Blueprint Render проверен по официальной JSON Schema.

Фактическое развёртывание в Render, его TLS и межсервисные ссылки ещё не проверены: для этого требуется аккаунт хостинга и создание платных ресурсов. Запущенный в рабочей среде сервер не является постоянным облачным хостингом.
