# Проверка первой версии

Проверено в рабочей среде 31 октября 2026 года.

- Backend: 15 интеграционных тестов успешно выполнены на PostgreSQL 17. Тесты используют отдельную временную схему, проверяют авторизацию, владение попытками, Origin, скрытие решения, легальные ходы, альтернативный мат, повторения, статистику, экспорт и восстановление прогресса, границы статических/API-маршрутов.
- Frontend: строгая проверка TypeScript и production-сборка Vite успешны.
- Docker: оба отдельных production-образа и единый образ для Render Free собраны; nginx → FastAPI → PostgreSQL и прямой FastAPI → PostgreSQL работают; Stockfish доступен. Единый контейнер дополнительно проверен с лимитом памяти 512 МБ.
- Chromium: проверены вход, фильтр мотивов/рейтинга, неверный ход, подсказка, полное решение с ответами соперника, Stockfish, показ и пошаговый просмотр решения, статистика, скачивание JSON-прогресса, выход. Ошибок JavaScript нет. Сценарий также прошёл через единый контейнер Render Free.
- Экран 390 px: горизонтального переполнения нет. SVG фигур загружаются успешно; права файлов проверены внутри nginx-образа.
- Данные: все 2500 исходных линий проверены на допустимость ходов; начальная позиция учитывает первый ход соперника. Источник и контрольная сумма — `data/puzzles.metadata.json`.
- PostgreSQL: создана резервная копия в custom-формате, её каталог прочитан через `pg_restore --list`; восстановление в отдельную пустую базу успешно, подтверждены все 2500 задач.
- Compose: конфигурации разработки и VPS проходят проверку синтаксиса. Blueprint Render проверен по официальной JSON Schema.

Фактическое развёртывание в Render, его TLS и соединение с облачной базой ещё не проверены: требуется запуск бесплатного Blueprint в аккаунте пользователя. Основной `render.yaml` содержит только планы Free; платная схема сохранена отдельно. Запущенный в рабочей среде сервер не является постоянным облачным хостингом.
