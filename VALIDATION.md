# Проверка первой версии

Проверено в рабочей среде 31 октября 2026 года.

- Backend: 15 интеграционных тестов успешно выполнены на PostgreSQL 17. Тесты используют отдельную временную схему, проверяют авторизацию, владение попытками, Origin, скрытие решения, легальные ходы, альтернативный мат, повторения, статистику, экспорт и восстановление прогресса, границы статических/API-маршрутов.
- Frontend: строгая проверка TypeScript и production-сборка Vite успешны.
- Docker: оба отдельных production-образа и единый образ для Render Free собраны; nginx → FastAPI → PostgreSQL и прямой FastAPI → PostgreSQL работают; Stockfish доступен. Единый контейнер дополнительно проверен с лимитом памяти 512 МБ.
- Chromium: проверены вход, фильтр мотивов/рейтинга, неверный ход, подсказка, полное решение с ответами соперника, Stockfish, показ и пошаговый просмотр решения, статистика, скачивание JSON-прогресса, выход. Ошибок JavaScript нет. Сценарий также прошёл через единый контейнер Render Free.
- Экран 390 px: горизонтального переполнения нет. SVG фигур загружаются успешно; права файлов проверены внутри nginx-образа.
- Данные: все 2500 исходных линий проверены на допустимость ходов; начальная позиция учитывает первый ход соперника. Источник и контрольная сумма — `data/puzzles.metadata.json`.
- PostgreSQL: создана резервная копия в custom-формате, её каталог прочитан через `pg_restore --list`; восстановление в отдельную пустую базу успешно, подтверждены все 2500 задач.
- Compose: конфигурации разработки и VPS проходят проверку синтаксиса. Blueprint Render проверен по официальной JSON Schema.

Бесплатная версия развёрнута на **https://tactics-trial.onrender.com/**. Проверка опубликованного адреса подтвердила HTTPS, HTTP 200 главной страницы, корректную выдачу JavaScript/CSS/SVG и `/api/health`: `status=ok`, `database=ok`, `engine_available=true`. `/api/auth/me` без сессии возвращает 401; запросы с origin сайта проходят к валидации API, посторонний origin отклоняется с 403. Вход с пользовательским паролем и авторизованные действия на опубликованном сайте не выполнялись; полный пользовательский сценарий проверен в локальном контейнере.

Основной `render.yaml` содержит только планы Free; платная схема сохранена отдельно. Ограничения бесплатной PostgreSQL и порядок экспорта прогресса описаны в `deploy/CLOUD.md`.

## Коллекции, генерация и импорт Chess.com

1 ноября 2026 года: 56 backend-тестов прошли на PostgreSQL 17, включая настоящий Stockfish. Проверены миграция, изоляция личных задач, выбор базы и прямой запуск, анализ только нужной стороны, повторные и пересекающиеся импорты, сохранение курсора и повтор после сбоя, конкурирующие запросы, внешние HTTP-ошибки и ограничения архива. Экспорт v2 восстанавливает личные и использованные открытые задачи даже после удаления исходных определений; старый v1 и замеры времени совместимы.

В стартовом корпусе 40 полных реальных партий из официального CC0-архива Lichess. Банк из 20 задач создан отдельно от готового CSV; независимый аудит 25 ходов ученика с очищенной хеш-таблицей Stockfish (до 1 млн узлов / 3 секунд) подтвердил легальность, исходную позицию, однозначность и завершённость решений. Исправления генератора покрыты регрессиями обязательного продолжения после взятия, тихого следующего хода, недостаточной глубины и доведения форсированного мата до конца. Источник, контрольные суммы, стадии партии и аудит записаны в `data/public-games.metadata.json`.

Live smoke публичного Chess.com API без ключа загрузил последнюю завершённую партию `erik` за 2026-10: 70 легальных полуходов, точное восстановление PGN. Проверены все 35 ходов этого игрока; ошибок выполнения нет. Пороговых улучшений в этой партии не найдено, что корректно даёт пустой список подходящих задач.

Сценарии Chromium на production bundle с управляемыми ответами API подтвердили импорт, паузу и ручное продолжение после скрытия вкладки, остановку после 503, сохранение задачи и прямой запуск. Проверены запоздавшие ответы списка/каталога/деталей, сброс прежнего мотива и режима повторения при прямом запуске, правильная база для следующей задачи и мобильная ширина 360 px.

Финальный единый образ Render Free собран и запущен с ограничениями 512 МБ памяти / 0,5 CPU. Chromium с настоящим API подтвердил выбор всех коллекций, полное решение задачи из новой базы, приблизительный рейтинг и таймер, создание подборки из 40 открытых партий, сохранение курсора, паузу и продолжение после навигации, экспорт определений задач v2. Ошибок JavaScript нет; библиотека, главная и статистика не переполняются на ширинах 360–1024 px.

Миграция `0003_collections_and_imports` и идемпотентная загрузка 20 новых задач выполняются при старте контейнера. Обновление подготовлено для ручного деплоя на Render; выполненные авторизованные проверки относятся к локальному контейнеру, а не к опубликованному сайту.
